# 멀티플레이 구현 상태

## 첫 연결 단계

- Unity Netcode for GameObjects 1.8.1과 Unity Transport를 사용한다. 프로젝트 Unity 버전은 2021.3.45f2다.
- 시작 화면 오른쪽 아래의 임시 메뉴에서 `Host game` 또는 `Join game`을 선택한다. 같은 컴퓨터에서는 `127.0.0.1`, 다른 컴퓨터에서는 호스트의 IP 주소를 입력한다. 기본 포트는 UDP 7777이다.
- 호스트가 기지를 열면 접속한 플레이어도 같은 기지 장면으로 이동한다. 출격 게이트에서 임무로 이동하면 연결된 플레이어 모두 같은 임무 장면을 연다.
- 각 플레이어는 자신의 기존 캐릭터를 조작한다. 다른 플레이어는 네트워크 아바타로 표시되며 위치와 방향이 동기화된다.
- 시작 화면의 기존 `작전 준비` 버튼은 혼자 플레이하는 경로다.

이 단계의 아바타는 위치 표시용이다. 공격, 체력, 적, 화물, 보상은 아직 서버 권한으로 동기화하지 않았다. 서버에 공개하기 전에 인증과 명령 검증도 구현해야 한다.

## 계정 저장 계획

Hostinger의 Debian 13 VPS에 **MySQL**을 설치한다. Unity 클라이언트는 DB에 직접 접속하지 않는다. 서버가 인증된 계정의 다음 데이터를 읽고 저장한다.

| 데이터 | 주요 항목 |
| --- | --- |
| 계정 | 계정 ID, 가입 시각 |
| 성장 | 레벨, 경험치, 재화 |
| 특성 | 계열별 투자 등급 |
| 장비 | 무기 해금 및 현재 선택 |
| 임무 보상 | 임무 ID와 계정 ID를 함께 기록하여 중복 지급 방지 |

현재 특성은 기기의 PlayerPrefs에 저장된다. 인증 및 MySQL 연동이 완료되기 전까지 이 값은 온라인 계정 데이터가 아니다.
